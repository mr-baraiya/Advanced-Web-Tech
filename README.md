# Advanced Web Technology – Lab & Projects

A complete collection of **Advanced Web Technology experiments and hands-on projects**, covering both **frontend and backend modern web development** using:

> **React (Advanced Hooks + Redux Toolkit) · Next.js · NestJS · TypeScript · API Development · Authentication · Performance Optimization**

---

## Repository Overview

This repository includes:

✅ Advanced React concepts (`useReducer`, `useCallback`, `useMemo`, Custom Hooks)  
✅ Redux / Redux Toolkit state management  
✅ Next.js routing, SSR (Server Side Rendering), ISR, API routes  
✅ NestJS backend development (Modular architecture, CRUD APIs, Auth)  
✅ Full-stack integrations with REST & GraphQL  
✅ Deployment-ready code structure  
✅ Bonus concepts → Web Security, Optimizations, and Best Practices

## How to Run Locally

### Clone the repository

```bash
git clone https://github.com/your-username/Advanced-Web-Tech.git
cd Advanced-Web-Tech
```

### Run Next.js application

```bash
cd first-app
npm install
npm run dev
```

The application will be available at `http://localhost:3000`

### Run Lab exercises

Open the HTML files in `Lab-1/` directory directly in your browser, or use a live server.
